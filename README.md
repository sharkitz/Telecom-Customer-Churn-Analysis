#  Telco Customer Churn Analysis

> 基于 Kaggle Telco Customer Churn 数据集的客户流失预测与归因分析项目。通过机器学习模型识别高流失风险客户，并提供可落地的业务干预建议。（也是涉及到类别不平衡的一个小练习）

## 核心结论 

本项目对比了逻辑回归与随机森林在客户流失预测上的表现，并进一步探究了模型表现差异的根因：

- **逻辑回归是更优的业务基线**：在默认参数下，逻辑回归取得了 **AUC 0.840 / Recall 0.802** 的优秀表现，能准确捕捉大部分流失客户。
- **随机森林的“低 Recall ”**：未调优的随机森林 Recall 仅为 0.449（漏报严重）。经排查，**根因是严重的类别不平衡**。引入 `class_weight='balanced'` 后，Recall 跃升至 0.797，且 AUC 基本持平。
- **三大流失驱动因素**：
  1. **月付合同 (Month-to-month)**：逻辑回归系数高达 -0.73，是最强的流失预测影响因素
  2. **在网时长 (Tenure)**：新客户流失率显著高于老客户。
  3. **光纤服务 + 电子支票**：高价光纤服务配合电子支票支付的用户群体流失率异常偏高。

## 业务建议 

基于模型归因与 EDA 分析，提出以下业务干预策略：

1. 提供新方案把月付客户转成长合同
2. 服务好入网时间较短的新客户，可以通过回访来增加新客户留下来的概率
3. 给高价光纤客户补增值服务


## 📊 分析流程 (Methodology)

| 阶段 | 核心内容 |
| :--- | :--- |
| **1. 探索性数据分析 (EDA)** | 整体流失率分布、互联网服务类型/支付方式与流失的交叉分析 |
| **2. 数据预处理** | `TotalCharges` 缺失值处理、低区分度特征剔除、分类变量编码 |
| **3. 模型构建** | 逻辑回归 (LR) vs 随机森林 (RF)，并设计 RF 的 `class_weight` 对照 |
| **4. 模型评估** | AUC-ROC、Recall、混淆矩阵、ROC 曲线对比 |
| **5. 业务归因** | LR 系数权重解读 + RF 特征重要性 (Feature Importance) 排序 |
